# Prépa ECG2

Application personnelle d'organisation de la prépa (PWA) : accueil, to-do intelligente, agenda, notes, échéances, méthodo.

- `src/` : sources (styles, données, logique, interface)
- `build.py` : assemble `index.html`, le manifeste, le service worker et les icônes
- `index.html` : l'app publiée (GitHub Pages)
